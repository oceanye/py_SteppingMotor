1. 安全须知（先读）

⚠️ 本系统为开环步进（无编码器），软件位置是脉冲累计的估算。断电、堵转、丢步、 中止运动后，实际位置可能与显示不一致。任何"位置可信"标记都只代表脉冲账本有效， 不代表电机真实到位。

  • 速度红线：脉冲率超过 1000 pps 时会弹窗要求确认；无加速曲线的开环步进 高速极易失步（啸叫、实际行程远小于设定）。带减速箱的轴尤其注意模式/减速比是否填对。
  • 急停优先：软件【停止】按钮和网页急停发 ESTOP 停全部输出； 现场应另配物理急停/断电手段。硬件急停触发后，释放按钮才能恢复操作。
  • 断开前必停：点"断开"前软件会先发 ESTOP 停车；若提示"停车未确认"， 说明控制器没响应，请立即物理急停。
  • 中止/异常后：轴位置会标记"不可信"（橙色），必须人工确认位置并重新校准后才能继续。
  • 三足步态：两模态模式的腿—高杆净间隙不足会禁止执行；旧固定增益模式保留仅提示行为， 不具有两模态避杆保证。通过软件校验也不等于全机现场安全验收。 运动中随时可【⛔ 中止】。

2. 快速开始：连接与模式

  1. ESP32-S3 接 USB（本机通常为 COM9），机构上电；双击 start_gui 启动。
  2. 左上角"串口连接"框：选择串口 → 波特率 115200 → 点【连接】。 成功后状态变绿"● 已连接"，固件自动回报模式（如 GEAR）。
  3. 连接时软件自动执行安全握手（ESTOP 全停确认），并按当前固件模式自动灰掉无关页。
  4. 模式选择：
    选项行为
    Auto（默认）向固件发 MODE 查询，按回报自动切换显示
    强制 FOC / 强制 GEAR跳过查询直接应用（用于旧固件无 MODE 命令时）
  5. 日志区在窗口底部，同日汇总写入 logs/gui_年-月-日.log； 排查问题先看日志，再看 logs/gui_stderr.log。

3. 电机绑定与状态

三足步态不直接使用"轴号"，而是使用四个逻辑角色，每个角色绑定一个物理步进轴：

角色含义要求
Mup1左侧直线升降直线模式
Mr1左侧转动旋转模式，必须绑定 ESP32 本地轴（0–5）
Mup2右侧直线升降直线模式
Mr2右侧转动旋转模式，必须绑定 ESP32 本地轴（0–5）
  • 在"🧭 电机绑定与状态"页为每个角色选择物理轴；【填充建议绑定】可一键填入推荐组合。
  • 草稿校验通过后点【保存】生效；换绑时对应轴必须空闲。
  • 换绑 / 改 PPR / 减速比后，步态零位标定自动失效，需要重新记零。

4. 步进轴页：单轴操作与校准

“🔩 步进轴 (30)”按 ESP32 本地 / Pico 1–4 分组，每轴一页。

4.1 轴参数（模式三联动，先填对再动）

参数含义范围
控制模式直线（mm）/ 旋转（°）按电机实际结构选
脉冲/转 (PPR)每转脉冲数（含细分）1 – 10000
减速比电机输出端减速0.001 – 1000
导程直线轴每转行程0.01 – 100 mm

参数改动实时保存到 .stepper_axis_config.json；换算出的 mm/°、速度单位随模式切换。

4.2 运动操作

  • 距离+方向 →【执行】：一段定长运动。
  • 点动（1mm）：短步进；按住连续：按住按钮持续走、松开停。
  • 前往位置：绝对定位；【⌂ 回零】= 前往 0。
  • 【⛔ 停止】：立即停该轴（发 STOP）。

4.3 位置校准与行程

  • 【⌂ 设为原点】：把当前位置定义为 0（可信）。
  • 【校准当前位置】：把手动摆到的实际位置填入"前往位置"框后点校准。
  • 【⊖ 最小 / ⊕ 最大】：标记软限位；越界目标会被拒绝。【清除行程】取消限位。
  • 位置显示蓝色 = 可信；橙色 ≈ 值（需校准） = 不可信，禁止运动。

5. 左右直联动与落地纠偏

位于“ESP32 本地”组内“轴 左右直联动”页：左右两条直线轴（Mup1/Mup2 对应轴） 同一命令同步执行，预检两轴都空闲才启动，防止只动一边。

落地纠偏（默认开启）：悬空腿落地时（两直轴标高差从大于阈值收敛到阈值内， 且只发生在单轴运动中），软件自动释放 Mr1/Mr2 旋转电机（断使能）， 让机构在重力下自正一次；直线运动结束后自动重新锁定。

  • 释放期间旋转轴禁止发脉冲；软件位置沿用不重算。
  • 阈值默认 3mm，可在联动页改；也可取消勾选关闭该功能。
  • 状态条：🔒 旋转电机已锁定（常态）/ 🔓 已释放 · 机构纠偏中（瞬时，通常 1–3 秒）。

6. FOC / 减速（GEAR）闭环页

  • 两套界面共用目标角变量；当前固件是哪种模式，哪组页可用（另一组灰）。
  • 使能 → 设目标角：电机闭环走位；watcher 每 1.5s 报进度，到位/超时会写日志。
  • FOC 调参：V（电压=扭矩）、PA（刚度）、VP（阻尼）；存 .foc_tune.json。
  • GEAR 调参：PWM 上限、Kp/Ki/Kd、GR 齿轮比；存 .gear_tune.json。
  • 自动调参：FOC 两阶段扫描 PA+VP（约 2 分钟）；GEAR 三阶段 Kp→Kd→Ki（约 3 分钟）。 电机会来回转动，确认机械空间后再点。
  • 波形图蓝=目标、红=实际，最近 10 秒。

7. 轨道 D

  • 独立 DRV8871 驱动的轨道电机；【◀ 按】/【▶ 按】按住走，松开停，占空比 1–100%。
  • 采用 800ms 租约：按住期间软件自动续租；松开或固件租约到期自动停。

8.2 角度联动原理（一句话版）

每步公转 φ=±60°（正为俯视顺时针）；世界相位 ψ 正为逆时针。 关节角始终为 Δq摆=Δψ+φ、Δq支=φ，然后按安装方向转换为电机指令。

两模态按当前支点方位和公转方向自动判断：公共低节点侧反向比例自转 Δψ=2φ， 一条 SYNC；公共高节点侧同向变比例自转，使用 60 段角度折线，每段双轴 SYNC、段末停稳。 初始 A/B 站位下，左顺／右逆属于前者，左逆／右顺属于后者；换位后必须重新判断，不能固定绑定按钮。

预览和腿—高杆校验使用同一执行折线。旧固定增益模式仍为 Δψ=kφ， 新模式忽略旧 k。角度→脉冲依赖 PPR、减速比和方向符号；尺寸决定净间隙， 不得为了让校验通过而虚填尺寸。详见 两模态交接说明。

8.3 一次完整步态的标准流程

  1. 前置检查：串口已连接；四角色已绑定；各轴位置可信（蓝色）。 旧配置不会自动升级轨迹；需主动选择两模态并核实几何模型和实测尺寸。
  2. 摆基准位：人工把三足摆到 左足 A、右足 B、三爪低节点（ψ=30° 位）， 四轴静止。
  3. 记零：【标定】页签 → 点 Mr1【记零】、Mr2【记零】， 零位标签从"未标定"变为具体角度。
  4. 确认复选框（最后一步勾！）：勾选 "已确认电机标定与现场支撑"。
    任何参数改动、任何记零操作都会把该复选框自动重置为未勾选。 所以顺序永远是：改参数 → 记零 → 勾选 → 立刻开始。
  5. 开始：预览通过后，右栏选择四个动作中的对应按钮。软件做全部前置检查 （绑定/固件 SYNC 能力/使能/零位/行程/线缆窗口）。
  6. 避杆门槛：两模态下，腿—高杆净间隙不足（含脉冲与初始相位误差包络）会拒绝开始。 未标定的占位尺寸可能正确地触发拒绝。旧模式的黄色“仅提示”不是新模式的避杆验收。 日志出现"步态执行器就绪（left）：N 个阶段"。
  7. 逐阶段执行：每按一次【✓ 确认并执行本阶段】推进一个阶段 （运动阶段发脉冲；人工确认阶段只推进）。阶段文本会说明当前要做什么。
  8. 完成：状态变 done，四轴释放；换另一侧时点对应的开始按钮， 软件自动使用新支点。

⛔ 中止 / 断连 / 急停后：步态标记"须人工恢复"——必须人工把机构摆回基准位， 【标定】页点【人工重建 A/B 基准】（不动电机），再重新记零、勾选、开始。 被 ABORT 的轴位置不可信，先单轴页校准。

8.4 实时数字孪生（无编码器估算）

  • 表格：四电机"估算坐标 / 指令目标"两列。
  • XY 示意：蓝=左足、橙=右足；实线=当前脉冲估算、虚线=指令目标； 顶行显示 φ / β / ψ。
  • Z 条：本步开始至今的升降位移 ΔZ（按抬升方向修正），不是实测离地高度。
  • 刷新随固件进度回报（SYNC 约 250ms 一帧）；断连 / 急停 / 坐标失信 / 超时 → 灰显冻结为"历史估算"，不伪造运动。
  • 步态完成后若又单独点动某轴：世界姿态失效，只显示轴坐标，不再画公转。
  • 孪生只读：不参与落脚、碰撞、电机控制的任何决策。

9. 手机网页控制

  1. 手机与台式机连同一局域网；GUI 启动后"手机完整网址"显示 http://<台式机IP>:8765/。
  2. 手机浏览器打开该网址（【复制手机网址】/【本机打开】按钮在左上第 3–4 行）。
  3. 页面显示"串口已连接"后即可控制：步进点动/定长、闭环目标角、轨道、急停。
网址固定、无鉴权，仅在可信局域网使用。日志会提示部署环境要求。
