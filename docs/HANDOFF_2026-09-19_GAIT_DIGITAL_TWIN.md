# 步态实时数字孪生（无编码器估算）

基线为 Gitea main `b452776`，在本地 `codex/gait-gui-layout-2026-09-18` 分支继续实现。
包含9月18日GUI布局修复；按2026-09-20要求与数字孪生一起纳入Gitea主线交付，不恢复或合并暂停的2209分支。

## 数据与显示

- 步态页增加实时视图：左右三足、横梁、φ/β/ψ、两侧升降位移和四电机坐标。
- 指令下发后，虚线与“指令目标”列显示目标位置；实线表示当前脉冲估算位置。
- 数据共用桌面/网页的已结算脉冲账本和固件 `STEP,...,P,...` 进度。
  完成前以“起点 + 有符号目标脉冲 × 已发/请求脉冲”换算位置；DONE结算后清除增量，避免重复累计。
- 界面沿用200ms刷新；实际更新密度受固件进度回报频率约束。SYNC固件约250ms回报一次。
  等待首帧时保留起点并显示目标，不按计时器自行走完整条规划轨迹。
  旧固件若没有进度回报，只能在终态更新坐标，不能提供连续中途位置。
- 数字和状态明确标注“估算 / 无编码器”；脉冲回报不是电机实际转角传感器。

## 参考系

XY示意采用横梁中心距 `d=1`，无需填写额外尺寸。三角支座与六边形为归一化示意，
不代表实测边界、实际毫米坐标或已通过避障校验。
既有尺寸仍在“几何参考”页，仅用于单独的轨迹/间隙参考图。

已知本步支点与方向后，用支撑电机相对同步段起点的关节角推算φ；
`β=β_start−φ`，两足世界姿态分别由 `ψ=30°+q+β−β_reference` 计算。
两侧安装方向符号、减速比及PPR均来自实际绑定轴。
Z显示本步开始时的升降轴坐标到当前位置的位移，按抬升方向修正；它不是实测离地高度。
本次沿用原有角度联动及可配置增益，不改变方向/速度/同步固件。

开始步态前可查看各电机软件坐标与旋转轴指针；未建立支点关系时不推断完整机构的世界姿态。
完成左步再开始右步会使用新支点与新的本步参考，避免套回初始A/B姿态或重复减横梁角。

## 异常与未来反馈

- 断连、停车/急停、坐标失信、进度超过1秒未更新：不产生新的有效姿态。
  同一标定/步态参考下保留最后一次有效姿态并灰显为历史估算；指令目标不再绘为当前运动。
- 换绑、PPR/减速比/方向/零位变化后旧参考失效，不重解释先前轨迹。
- 步态完成后发生独立点动或网页运动：继续显示各轴坐标，但支点未确认，不再推算公转。
- 数字孪生只读取数据，不写入已结算坐标，也不作为落脚、碰撞或电机控制的反馈。
- 数据对象独立提供 `source`、`measured`、`pose`、`target_pose` 与状态字段。
  当前始终 `source=commanded_pulses`、`measured=false`；编码器尚未接入。
  后续应另接实测通道，再与指令目标/脉冲估算比较，不能将现有估算直接改名为实测。
