# 2026-10-06 当前步滑窗、固定纵轴与灰色落点候选

## 用户要求与实现

1. 曲线只反映当前步，使用固定90秒滑动窗口；地图仍累计多步位置与路径。
2. 距离纵轴固定为 **−20～200 mm**，不再随数据最大/最小值跳动；没有数据也显示坐标轴。
3. 去掉桌面的独立“单步预览/校验”“回放预览”按钮和“预览”数据源单选项。
   点击左顺／左逆／右顺／右逆之一，自动校验并在地图叠加灰色虚线候选足及横梁。
4. 真机开始后，曲线只使用本次实际执行计划的灰色参考，旧模拟步不混入；预留独立编码器层。

本轮改的是显示、候选交互和只读执行计划元数据，不改HIGH/LOW轨迹、碰撞门槛、
SYNC指令、四轴绑定、标定或固件。独立分支：`codex/twin-window-gitea-review-2026-10-04`。

## 1. 横轴口径：本步S4模型进度，不是实际耗时

平面避杆关键段为S4自转—公转。若直接按真实秒或完整阶段模拟秒滚动，抬脚、落脚、
人工确认和通讯等待会把关键避让曲线挤出窗口；也会造成灰色计划与真实执行进度错位。

因此当前各来源统一用 **本步S4模型进度秒**：

- 时间表来自原规划器同一路径、方向和分段五次进度时钟；正反向均适用。
- 模拟用当前虚拟公转角φ定位时间表；真机用当前可信的脉冲公转角φ定位。
- S4前保持0；S4后保持终点；抬升、落足、等待不推进曲线游标。
- 断连/进度失信时，模型游标停在最近有效位置；不会靠墙钟继续播放。
- 当前进度≤90秒，窗口为0～90；超过90秒后显示“当前−90～当前”。
- 下一步时间重置为0，清掉旧曲线；地图世界路径、完成步数仍连续积累。
- 窗口边界按相邻同段样本插值裁切，不跨断流段连接；超出窗外的旧最低值不参与窗口统计。

横轴不能用于测量真机速度、通讯时延或真实执行总时长。灰线中的未来段只是计划参考，
不是已经完成的电机位置；地图当前位置仍来自独立的当前数据源。

## 2. 固定纵轴与碰撞读法

固定刻度为 −20、0、50、100、150、200 mm；红色0线、0以下淡红背景。
超过固定量程时保留数值并提示实际范围，绘图限制在边界，不静默自动缩放。
修改范围时统一调整 `motor_control/gait_curve.py` 中常量，主窗口和大图共用。

**指标未改变：六爪端点到邻域高杆表面的最近距离。**

- 负值：该爪端点进入杆的平面投影；0：接触杆投影边界。
- 正值：仅说明爪端点与杆表面分离，**不能证明整条腿没有扫到高杆**。
- 粗线是六爪端距离最小包络；δ虚线是参考间隙，不是整腿安全认证边界。
- 真正执行前的整腿包络、杆半径、要求安全间隙和采样保守修正等校验保持原样。

默认投影边长190 mm、派生中心距约329.09 mm继续保留；未确认的腿/杆投影宽度仍需现场测量。

## 3. 直接点选四动作

桌面正常只提供“模拟”“实机”两类数据源；选动作即显示一个灰色候选，不另开预览状态。

| 当前来源 | 候选基于 | 点选动作是否移动/保存 |
|---|---|---|
| 累计模拟已有站位 | 最新虚拟左右足、相位、支点 | 不累计下一步，不写实机参数 |
| 模拟未开始 | 所选起步两格 | 只计算临时候选，不创建已完成步 |
| 实机观察 | 当前真实执行账本的站位/横梁角；无可信姿态时仅为计划假设 | 不下发指令、不保存标定 |

灰色候选足、横梁和“候选落点”标注叠加在地图上；已有模拟/实机姿态不会被替换为目标位置。
校验失败时仍可查看候选，但明确提示拒绝执行；非法参数或越界则不保留旧候选。
参数修改、起步/站位变化、开始模拟或真机后，旧候选失效。
运动中动作选择不可改变当前步；模拟下一步和四个【开始…移】仍是分开的明确入口。

旧预览API仅为兼容已有调用/回归保留，正常桌面没有独立入口；重置真机流程也不恢复旧预览。
移除按钮不等于移除安全干跑：开始真机仍会重新执行完整前置与避杆校验。

## 4. 真机灰色参考与编码器预留

执行器完成前检后附带只读 `twin_report`、`twin_psis`，用于显示本次实际动作的计划。
保留S3相位调整后的爪序号，避免多步后把左1/左2/左3等曲线错配。
显示缓存以执行实例、世界原点、参数为标识；新步替换，重置/更换原点/几何/失去基准时清除。
主窗口、大图共享同一份参考和数据缓存，没有第二个控制器或采样线程。

| 图层 | 颜色/状态 | 当前数据来源 |
|---|---|---|
| 模拟当前步曲线 | 左足蓝系、右足橙系 | 虚拟S4姿态，非实测 |
| 真机当前步参考 | 灰色虚线/灰色最小包络 | 当前执行器的已校验计划 |
| 真机地图、轴坐标 | 原有实机估算样式 | 指令脉冲进度，不是编码器 |
| 编码器曲线 | 当前为空，显示“未接入” | 未来适配器提供真实数据后才绘制彩色层 |

预留 `EncoderCurveBuffer` 显示边界，**不是已完成的编码器驱动**：

```python
# 未来的编码器适配器在Tk线程投递，不能把 commanded_pulses 送到这里。
buffer = view["encoder_curve"]
buffer.append(current_step_key, s4_model_time_s, six_tip_distances_mm,
              source="encoder")
```

要求当前步标识、有限非负且不倒退的模型进度时间、六个有限距离值和明确的encoder来源。
旧步/指令来源/非有限值拒绝；新步或世界基准变化清旧测量。当前代码没有调用该接口的设备采集器，
不会自行生成实测点。未来接入还需完成编码器标定、时间/相位配准、数据有效性与断流分段处理，
不能仅把脉冲位置改个名字后送入此层；本接口亦不参与电机闭环控制。
