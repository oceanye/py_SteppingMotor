# 步态页布局与参数用途

基线：Gitea main `b452776`；工作分支：`codex/gait-gui-layout-2026-09-18`。

## 检查结果

主线的 `b452776` 增加纵向滚动条，但 Canvas 不会根据内部表单自动申请宽度；
内部窗口又被强制压到 Canvas 宽度，输入框实际超出了视口。
右侧预览图和说明横向并排，且只有左侧列配置伸缩权重，进一步挤压左栏。
已在真实 Tk 中用 720、1024 像素宽的独立步态页复现输入框横向裁切。

旋转轨迹仍为 φ=60°、Δψ=kφ、Δq摆=(k+1)φ、Δq支=φ。
中心距、六边形节点环半径和壳体尺寸不改变这些角度，也不用于把角度换算成脉冲。
角度转脉冲使用绑定轴的 PPR、减速比及方向标定。

## 页面调整

- 左侧分为“运行”“标定”“几何参考”三个页签，默认显示运行。
- 运行页：增益、公转峰值速度、线缆角度限位、实际抬足行程、抬落速度、参考安全间隙。
- 标定页：横梁基准角、四轴方向、旋转零位、现场标定确认和物理基准恢复。
- 几何参考页：原有中心距、节点环半径、各结构尺寸和预览采样参数。旧配置保留，无需日常重复填写。
- 左右分栏可拖动；表单保留必要宽度，窗口偏小或高 DPI 时提供横向/纵向滚动。
- Tab 聚焦时自动滚动至对应控件；滚轮只处理所在表单，避免误改方向下拉框。
- 实机阶段控件优先显示，图示移到下方并随宽度缩放；“中止”固定在右栏顶部。
- 保存/重读按钮和标定状态留在左栏底部，独立于参数页滚动内容。
- 数值加载保持浮点精度；原先 `:g` 默认6位有效数字会把 `d=√3R` 的合法紧贴配置截短，导致只改角度再保存时误报模型重叠。已复现并修复。

抬足行程是升降电机的实际位移，不能从旋转角度或安全间隙直接推导，因此保留。
安全间隙 δ 是几何模型的扣减余量，不是额外抬升指令。
若要量化“实际间隙多少毫米”，仍需要结构尺寸；没有实测尺寸时，图示和间隙结果仅是参考。
本次没有新增“六边形边长”或“支座间距”必填项，没有修改已保存的 `.gait_params.json`。
