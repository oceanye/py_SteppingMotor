# 5×5 行走地图、起步选格与多步数字孪生

基线：Gitea main `cb367b9`。
实现分支：`codex/gait-twin-map-5x5-2026-09-29`。

## 本次交付

- 数字孪生固定为 5 行 × 5 列、25 个共边六边形；可放大、缩小、平移、全图复位。
- 起步时分别选择左足、右足所在六边形，必须不同且共边相邻。
- 选格与真实步态共用支座坐标，不是给画面单独加平移。
- 连续换位保留左右足中心及机构中点的历史 XY 轨迹、完成步落脚标记和编号。
- 支持隐藏路径、清空路径；清空只改变显示记录，不重置机构位置、零位或电机脉冲坐标。
- 显示两足及机构中点 XY，继续标明“脉冲估算 / 无编码器”。

不改 LOW/HIGH 的自转—公转函数、S0–S7 执行顺序、固件、协议、电机绑定或驱动配置。
5×5 是可选择/可落脚区域，不是“只能走 25 步”，允许往返。
不新增自动路径搜索或多步动作队列：现有“一键执行”仍只执行当前一步的剩余阶段。

## 操作顺序

1. 确认电机全部静止、旋转轴已锁定。在步态页的数字孪生区选择两格：
   - 用左右足各自的下拉框；或选“地图选左足/右足”，再点击地图中的六边形。
   - 选格支持已缩放/平移的画面；选择只改变待应用项，不改变物理基准。
   - “仅浏览”停止点击选格，保留缩放功能。
2. 人工把机构放到所选两格，三爪踩低节点，点击“应用起步位置”并确认。
   - 此按钮不会移动任何电机，也不会重写电机软件坐标。
   - 同时保留并保存当前输入框中的有效参数；无效参数会阻止应用。
   - 应用后清除旧历史、旧零位与标定确认，自动计算横梁基准角及红杆侧别。
3. 重新记左右旋转轴零位，确认方向、PPR、现场支撑及标定，然后按原流程执行。
4. 后续每一步沿用同一世界坐标，不要为继续下一步重复“应用起步位置”。
5. 要清除已走路线，点击“清空路径”。当前姿态、在执行的动作、原点、缩放均保留；
   从清空时刻继续记录，已完成步数从零重新计数，不会重计正在显示的已完成一步。
6. “显示路径”仅隐藏/显示，隐藏期间仍记录；“全图”仅重置视角，不清路径。

改起步位置、重建物理基准和清空路径是三种不同操作，不可互相替代。
起步配置不是实时测量；未标定/未开始步态时地图标出起步两格，不伪造实时机构姿态。

## 坐标与模态

世界原点固定在 B，+X 向右、+Y 向上，中心距归一化为 1；A=(-1,0)，B=(0,0)，
C=(-0.5,√3/2)。无需为画路线新增六边形长度、距离等输入。

晶格轴坐标 `(i,j)` 与世界坐标的换算：

```text
x = i + j/2
y = √3·j/2
j ∈ [-2,2]
列偏移 c = i + floor(j/2) ∈ [-2,2]
界面行号 = j+3，列号 = c+3
```

这是错列排列的 5×5，而非轴坐标直接取正方形形成的斜平行四边形。
行号从下向上，A 为 3行2列，B 为 3行3列，C 为 4行2列。
任意一对相邻格有序地指定左右足后，横梁角 β₀ 指向“右足→左足”：

| β₀ | 紧邻横梁的红杆侧别（站在左足看向右足） |
| --- | --- |
| 0°、120°、240° | 左侧 |
| 60°、180°、300° | 右侧 |

两足零位仍对应世界爪相位 ψ=30°（模 120°）。LOW/HIGH 仍由当前支点、摆动方位和
±60° 换位方向分类，不能仅按起步的红杆侧别永久绑定某个按钮。
地图中点轨迹仅表示两足中心的几何中点，不是经过力学计算的真实重心轨迹。

## 控制与数据边界

- 只允许在图内的支座起步/落脚。图外目标在固件探测、使能和运动下发前拒绝。
  预览采用同一规则，不能在越界时退回 A/B 示例路线。边界可选合法的反向动作返回。
- 不把障碍范围裁到 25 格：避杆几何继续纳入支点周围、包括地图外的高杆。
  本次不扩大任何既有避障认证范围；地图边界检查也不是完整机构包络的边界碰撞检查。
- 调整起点时检查步态占用、独立/网页运动、待下发运动、旋转释放、停止未确认等状态；
  确认框返回后再次检查。保存失败不发布新站位，不修改轴的位置可信状态。
- `.gait_params.json` 新增可选 `initial_pad_pair`（有序 `[左足支座, 右足支座]`）。
  缺字段/null 保留原 A/B 预设及旧摆放迁移。新字段非空时，必须与 β₀/侧别同时一致，
  不用旧侧别迁移逻辑静默修正错误的新配置。不要用旧版本软件解释新地图配置。
- 初始选格可保存；当前走到的位置与历史路径不跨进程恢复。
  重启仍要人工确认实际起步位置和标定，不能把保存的初始选格当成断电时的实测位置。
- 历史只记录有效脉冲姿态，不读取未来指令目标、不按时间推演运动。
  断连/过期/失信不加点；恢复时分段，不用直线把未知运动补齐。
  每一步也是独立轨迹段，避免把落脚后的理想支座对齐误差画成实际移动。
- 路径最多缓存 6000 个姿态点、250 组完成步标记，超限滚动保留最新部分，避免长时运行内存无界增长。
- 没有编码器，失步、足底滑动、被动释放后偏转不能被本功能检测。
  现有落脚推算仍以理想支座位置为基础；不能用数字孪生证明实机没有碰撞。
