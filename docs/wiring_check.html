7. 共地汇合点（最关键的一个端子）

买一个 6~8 位的接线柱，把以下所有 GND 汇到同一颗螺丝上：

  • 24V 电源 - 输出
  • 12V 电源 - 输出（或 24V→12V 降压模块输出 GND）
  • ESP32 GND 排针
  • DM422 #0 V-
  • DM422 #1 V-
  • DM422 #0 PUL- 和 DIR-
  • DM422 #1 PUL- 和 DIR-
  • DRV8871 #0 Power-
  • DRV8871 #1 Power-
  • 编码器 #0 GND
  • 编码器 #1 GND

8. 上电前逐项检查（断电状态用万用表）

电源接错检查

  • 24V 电源 +/- 接入 DM422，正负无反接
  • 12V 电源 +/- 接入 DRV8871 Power+/-，正负无反接
  • DRV8871 的 VM 端子留空（接 24V 会烧 N20，接 12V 也比直接走 Power+ 缺保护）
  • 编码器 VCC 接到 ESP32 3V3，不是 5V（即使编码器规格支持 5V，3.3V 更安全）

共地连通检查

  • 万用表测：24V 电源 GND ↔ 共地汇合点 = 0Ω
  • 万用表测：12V 电源 GND ↔ 共地汇合点 = 0Ω
  • 万用表测：ESP32 GND 排针 ↔ 共地汇合点 = 0Ω

短路检查（断电下用阻值档）

  • 24V 电源 + ↔ GND = 几 kΩ – MΩ（不应该 < 100Ω）
  • 12V 电源 + ↔ GND = 几 kΩ – MΩ
  • ESP32 3V3 ↔ GND = 几 kΩ – MΩ
  • DRV8871 #0 Power+ ↔ Power- = 几 kΩ（H 桥开路 + 滤波电容）
  • DRV8871 #1 Power+ ↔ Power- = 几 kΩ

9. 上电顺序

  1. 所有线接好，但 24V / 12V 电源开关 OFF，ESP32 USB 不插
  2. 万用表做上面 §8 检查全部通过
  3. 先开 12V 电源，确认稳定 12V 不进 CC（电流 < 50mA 空载）
  4. 再开 24V 电源，确认稳定 24V，DM422 灯亮
  5. 最后插 ESP32 USB，打开串口监视器（COM9, 115200, Newline）
  6. 启动 banner 应出现：ESP32 Controller Ready (GEAR mode, stepper + DC gear motor)
  7. 电机暂时不会动，PWM 都是 0

10. GUI 启动 + 首次测试

  1. python pc_gui.py
  2. 选串口 COM9 → 点"连接"
  3. "生效模式"应显示 GEAR（绿色）
  4. GUI 自动跳到 ⚙ 减速 L tab
  5. 把 Kp 滑块拉到 20 → 松鼠标看 💾 保存日志
  6. "使能 PID" → 状态变"运行"
  7. 目标 45° → 前往，watcher 日志应该看到 ✓ 到位
  8. 切到 ⚙ 减速 R tab，同样操作（Kp 起步 10，Kd 0.3，Ki 0.5）
  9. 步进 L / R tab 也试一下"向外 1mm"按钮

11. 故障排除速查

现象原因修法
电源开机进 CC（电压被压到 < 5V） VM 端子误接到电源 +，或者电机 OUT 短路到 GND 关电源，万用表测 §8 短路检查
ESP32 USB 一插就发烫 3.3V 轨被外部短路（编码器 VCC 接错？） 立刻断电，检查 3.3V ↔ GND 阻值
GUI 连接后"生效模式 = ?" 固件没烧最新版（缺 MODE 命令） pio run -e esp32s3_gear -t upload
电机使能后立刻 runaway 编码器方向反 或 电机方向反 看日志 cur 走向，对调对应 OUT 或 ENC 线
"前往" 后电机不动 Kp 太小，跨不过死区 把 Kp 滑块拉到 20+
电机过冲且卡死 Kp 大、Kd 小、齿轮静摩擦锁死 减 Kp、加 Kd、加少量 Ki
