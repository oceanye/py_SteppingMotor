## 2. 软件新增：脉冲率安全护栏（本次提交）

动机：轴 L（ppr=200, gr=21.5）误切直线模式时，最慢速度档 0.3 mm/s 即折合
1290 pps，电机啸叫丢步且无任何提示（HANDOFF_2026-08-19 §5.1/§5.3）。

实现（`motor_control/axis_math.py` + `desktop_app.py`）：

- `PULSE_RATE_WARN_PPS = 1000`：执行运动/快捷/前往位置入口弹"速度过高确认"
  对话框（`_speed_safety_ok`），可取消；按住连续模式只记日志不弹窗。
- `speed_clamps_delay()`：请求速度折合 >4000 pps（0.05ms 下限+200us 补偿）时，
  日志提示"实际将按钳位执行（比设定更慢）"，同状态只提醒一次。
- `delay_ms_to_pulse_rate()`：固件延时→脉冲率换算。
- 新增 `tests/test_pulse_rate_guard.py` 8 项：换算边界、钳位一致性、
  轴L直线最慢档必拦、轴R 1/3 mm/s 不误报、轴L旋转 3°/s 不受影响。
- 回归：106/106 unittest 通过（Python 3.13 venv），compileall 通过。
- 用户已现场验证弹窗生效（08-20）。

阈值依据：200 整步无加速曲线的启动/运行安全参考；轴 R 高速档（5/10 mm/s）
会弹一次确认，属诚实提醒而非误报。

## 4. GUI 三优化 + 中文输入法小数输入修复（本次提交）

用户需求：①窗口一页放下全部内容 ②旋转态"距离 (°)"改"角度 (°)"
③减速比输不进小数；追加 ④速度档位扩充。全部完成并经真机验证。

- **排版**：间距常量统一到 `motor_control/ui/common.py` 的 `PAD`
  （四个 Tab 构建模块共用，以后调间距只改一处）；日志区 10→6 行。
  窗口需求高度 **1106px → 885px**（1080p 屏可用 1000px，旧版被截
  106px 即"遮住信息"的根源）。
- **角度标签**：stepper_tab 初始构建 + desktop_app `_refresh_axis_unit_labels`
  动态刷新两处，30 轴全覆盖；手机网页同步（`web/index.html` 加 snoun span）。
- **小数输入（三轮攻坚，病根两个）**：
  1. 全角字符（０-９．。，－）进框后 DoubleVar 毒化不可读 → 全部转半角；
  2. 按键探针 `logs/key_probe.log` 实录：NumLock 开 + 中文输入法下，
     小键盘'.'事件形态为 **char='.' + keysym='Delete' + keycode=46**，
     放行给输入框默认处理会被当删除键丢弃（"按一次没反应按两次才进"
     的真凶）；第二次按输入法改发 char='。'（keycode=12290=字符码点，
     非物理键码）。修法：合法数字字符一律由 `_filter_key` 亲手插入，
     键名/键码兜底（period/KP_Decimal/190/110/189）+ 全角转换 + 失焦
     恢复最后有效值。异常按键持续记入探针日志备查。
- **速度档位**：18 档 → 24 档（加 0.05/0.1/0.2 微动 + 15/20/30 快移；
  >1000pps 弹窗、>4000pps 钳位提醒护栏不变）。
- 回归：118/118 unittest（+12 输入规范化纯函数测试，注意正则必须
  `re.ASCII`，默认 \d 认全角数字）、compileall、真机验证通过。
