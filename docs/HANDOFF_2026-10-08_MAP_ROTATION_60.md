# 2026-10-08 平面地图整体旋转60°

## 使用方式

主界面地图工具区及大图工具栏新增 **地图逆时针旋转60°** 复选框。
默认未勾选为0°；勾选为逆时针60°，取消勾选还原。地图左上显示当前视角。
这是本次GUI会话的显示选项，不保存到电机/标定配置。

- 整个5×5地图的六边形、高低杆节点、当前机构姿态、最近两步轨迹、虚线候选/预计落点统一旋转。
- 文字保持正向可读；右侧距离曲线、轴坐标表、升降ΔZ条不旋转。
- 世界坐标、A/B/C及行列编号、左右足身份、真实步态方向不变。屏幕上方不再必然是世界+Y；不可把视角旋转理解为重建零位。
- 主面板与大图共享旋转开关，缩放和平移各自独立。全图/双击只复位缩放和平移，仍保留旋转选项。
- 图面选起步格子仍按同一个世界格子命中，旋转不会应用新起步位置；应用起步位置仍需原有确认/空闲检查。
- 运行期间可切换视角，不暂停/启动电机，不清轨迹、不改变时间轴，不重新做轨迹规划。

## 实现

`ui/gait_twin.py::twin_projection()` 在显示边界中心执行二维刚性旋转：
`rx = cosθ·x − sinθ·y`，`ry = sinθ·x + cosθ·y`，再转为屏幕坐标（屏幕Y向下）。
投影使用旋转后的包围盒确定等比缩放，默认全图状态下25格仍全部可见；
最后应用既有鼠标缩放/平移，保留指针固定点行为。后台地图和规划数据完全不修改。

背景缓存键包含旋转角度，避免地图背景不转而轨迹旋转；所有几何层和选点共用 `project()`。
`ui/gait_twin_window.py` 共享旋转变量并同步重画两窗口；工具栏根据宽度换行。
