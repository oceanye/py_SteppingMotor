# 自转—公转角度联动修复与实机验收

基线：Gitea main `8d23f9c`。独立分支：`codex/angular-orbit-linkage-2026-09-18`。
不合并、不恢复 TMC2209 分支；本次没有烧录、连接串口或发送实际电机运动命令。

## 需求依据及原实现偏差

完整阅读 `handoff_control_method_utf8.txt`（UTF-8）和
`handoff_motor_control_check.txt`（本机新提供文件，GBK/CP936；原文件不改写）。

两份文件的伪代码对横梁转角正负约定不同。本实现遵循第一份明确的
A→C 几何：以右足 B 为支点，横梁角 β 从180°降至120°，公转进度 φ 从0°升至60°。
右足下一步 B→A 时，β从120°降至60°，不是把右侧圆弧方位300°误当成新的横梁零位。

旧实现为限制绕线，选了 `Δq=60+120k` 的终点等效小步；从零位通常选60°。
这导致摆动足世界自转增量为0°，虽然终点三爪落点等效，中途避让完全不同。
此外，独立MOVE串行ACK、独立梯形加减速、逐段脉冲取整都不能保证全过程角度比例。
旧碰撞检查还跳过壳体投影下的高点，并只默认检查三座六边形。

## 统一角度模型

角度均以度表示；q是足相对于横梁的关节角，ψ是世界姿态，β是横梁世界角。
安装方向通过各旋转角色 sign 标定，不把旋转角当作直线毫米转换。

```
u = 10s³ - 15s⁴ + 6s⁵
φ = 60u
β = β_start - φ
ψ_swing = ψ_start + kφ
Δq_swing = (k+1)φ
Δq_support = φ
q = ψ - β + c
```

默认 k=2：公转60°，摆动足自转120°，摆动关节180°，支撑关节60°。
φ=30°时，ψ=90°（初始ψ=30°），爪臂朝90°/210°/330°，而非零自转。
中心距d、爪长、升降行程只影响几何校验，不改变旋转电机角度比例。
增益可配置，目前允许2/4/6/8/10，保证60°终点仍对准120°对称低节点；每个候选必须重新校验全程，不能视为天然安全。

**禁止在公转过程中自动替换解绕路径。** 线缆窗口不足时在抬足前拒绝执行。
若以后需要连续解绕，必须单独规划悬空、原地解绕阶段，验证其全扫掠轨迹和支撑条件，不能靠终点等效跳过。

## 高点与结构包络校验

- 自动纳入A/B/C周围的六边形邻座。紧贴正六边形应实测中心距；理想值 `d=√3·节点环半径`，不是现有占位220mm就代表紧贴模型。
- 高节点按有半径、有高度的竖直障碍包络；三爪按胶囊体。
- 壳体/电机/轴承由中心圆盘水平包络与最低点下伸量保守覆盖，横梁/连接件用线段胶囊及最低中心线高度覆盖。
- 不再跳过壳体投影内的节点；即使水平投影相交，也必须用实测垂向间隙判断，不能靠“目视飞越”就宣称可行。
- 相邻采样间扣除 `(d+kR)·Δφ/2` 的运动距离界，得到连续间隙保守下界；稀采样可能拒绝，但不能把中途穿过节点误判为可行。
- S3原地相位调整也检查完整扫掠；实际执行额外保留脉冲取整、DDA比例量化和初始角度误差包络。
- 默认抬升10mm、高低差12mm是**不允许执行的占位组合**。必须实测并选择实际可达到的安全抬升高度，不得为了放行而虚改高差或缩小结构包络。

现场参数：爪臂长度/粗细、高节点半径/高低差、壳体和电机等全部结构的水平包络、最低点下伸、横梁及连接件的最低中心线高度和半径、安全间隙。
结构包络须涵盖整个动作期间的实际最低/最外位置；模型不涵盖未录入的异形突出件、支座朝向偏差或额外障碍。

## 实际电机执行链路

规划器与执行器共用角度目标。S4整条轨迹一次下发，ESP32单任务、公共时基、五次进度、DDA脉冲分配：

```
SYNC,S                         # 只读能力查询
OK,SYNC,V1,6
SYNC,a,signed_steps_a,b,signed_steps_b,duration_us
OK,SYNC,a,b
STEP,a,P,executed,total        # 原有进度格式
STEP,b,P,executed,total
STEP,a,DONE,executed,total     # 或 ABORT
STEP,b,DONE,executed,total
```

signed_steps 的符号表示实际DIR电平，不是软件坐标方向；主机分别记账软件有符号脉冲。
任一同步轴STOP/急停会中止整对。固件忙/失能/参数错误不能启动半条同步轨迹。
步态DONE必须带有与主机命令一致的完整脉冲计数；部分完成、错误总数或缺失计数按ABORT处理，禁止继续落脚。
峰值限制5000pps，单条轨迹时长1ms～120s；主机还应用既有更保守速度护栏，并在抬足前检查所有阶段的脉冲数、时长、软件行程及线缆角窗口。
调度晚点不突发追赶；两轴保持共同路径进度，实际总时长可能比计划长，仍非硬实时/编码器闭环保证。

只支持两个ESP32本地旋转轴。旧固件通过只读能力查询，在抬足前拒绝；跨Pico/RS485节点没有公共时基，因此明确拒绝，不能回退为独立MOVE。
支持SYNC的FOC固件也能编译，但其仅2个本地轴不能承担当前四角色步态；桌面四角色步态要求六轴GEAR能力。

四个绑定轴在整个分阶段动作（包括等待人工确认期间）均被预约，避免点动、网页运动、换绑及改参数插入。
步态期间禁用独立“落地释放旋转电机纠偏”，避免破坏支撑足世界姿态与累计角。
ENA回执匹配也校验请求的锁定/释放状态，迟到的释放回执不能确认新的锁定。
任何自由释放旋转轴都会使脉冲位置失去可信度，重新使能不等于重新标定。

## 标定与运行操作

1. 先核实主线驱动器与实际接线、使能极性和模组GPIO可用性；尤其GPIO36需要按实际ESP32模组确认。不要在2209调试板上直接烧录本分支主线驱动固件。
2. 绑定四角色（建议Mup1→0、Mr1→2、Mup2→1、Mr2→3），分别选择直线/旋转模式，填写实测PPR、减速比、升降导程及上下限；先安全点动验证方向和坐标可信。
3. 人工建立左A/右B双足支撑基准，β=180°，三爪都踩低节点。需要恢复时使用“人工重建A/B物理基准”：按钮不移动电机，也不凭软件把电机位置强行设零。
4. 录入实测几何与结构包络，验证电机定子/横梁/转子/三足的反力闭合；不能只验证空载自转就认定公转机构有效。
5. 三足摆到ψ=30°基准，分别记两侧Mr零位。记零保存对应轴、PPR/减速比和方向签名；换绑、改变参数或方向后必须重新记零，不能仅重新勾“已标定”。
6. 勾选实测与机械标定确认，保存，预览/校验。旧配置和重启后的程序不会自动继承“可运行”确认；支座状态不是编码器实测结果。
7. 开始一次左侧换位。S0检查双足接触，S1人工确认支撑锁定，S2抬足后确认三个接触点都解除，S3若必要作已验证的相位调整，S4双轴同步公转自转，S5确认目标三低节点对应，S6低速落脚，S7人工确认三点接触/载荷/锁定完成。
8. 完成S7才更新支座状态和横梁脉冲估算角；下一步右侧换位为 `(C,B)→(C,A)`，继续时按当前支座计算路线，不反复套初始A→C。
9. ±180°窗口不能保证连续多步：会在某步提前拒绝。不要扩大窗口超过真实线缆/机械允许值；另行验证解绕或安全恢复后再继续。
10. ABORT、未确认的同步命令、异常、急停或流程中止后，禁止直接重开下一步。人工恢复安全双足支撑，重建基准、确认位置并重新标定。

界面显示φ、β、摆动Δψ及两侧Δq，标注“脉冲估算，非实测”。规划图仍不是实际位置传感器。

## 已实现与硬件依赖边界

| 需求 | 本分支落实 | 仍须实机确认/反馈 |
| --- | --- | --- |
| 自转和公转角度关联 | 全过程共用角度模型，默认180:60关节比例 | 安装方向、机械反力闭合、不失步 |
| 高点避让 | 邻座、爪、壳体/电机/轴承、横梁包络、连续下界及量化包络 | 实测尺寸、高差、突出件及结构变形 |
| 电机真实联动 | 原子双轴SYNC固件与桌面执行器，不局限预览 | 两路STEP/DIR波形、相位误差与负载 |
| 双足互锁 | 四轴全程占用，禁止外部插入和落地自动释放 | 独立接触检测以证明至少一组三爪有效支撑 |
| 低速落脚/三点确认 | 分阶段落脚、人工确认后再转移支撑状态 | 三点接触、低节点识别、载荷反馈 |
| 过流、堵转、力矩/支撑力保持 | 现有STEP/DIR驱动只能保持使能与位置命令；不能虚构测量 | 驱动电流/故障反馈、编码器、支撑力传感器 |
| 实际φ、β、ψ跟踪 | 实际已发脉冲进度的估算，明确非实测 | 横梁角度和两侧编码器，才能闭环纠偏 |

因此：**已实现可标定后使用的分阶段真实电机联动，不是宣称已完成无人看管的自主闭环步行。**
缺少传感器时接触、载荷、离地及锁定通过逐阶段人工确认；不得用DONE代替三爪接触证据，不能把使能保持冒充限矩/柔顺控制。

远端验收顺序：

1. 审核独立分支与参数迁移；确认无2209代码混入。
2. 编译GEAR及所用硬件急停配置；补跑native_test，检查实际板型与GPIO、ENA极性。
3. 空载断开动力风险，用逻辑分析仪检查同步两路STEP/DIR、3:1角度关系（按各轴PPU换算）、五次进度、任一STOP同时ABORT、忙拒绝无半启动。
4. 使用固定支撑架/防跌落措施，低速标定、验证反力闭合和世界姿态保持，再验证左A→C、右B→A。
5. 实测轨迹所有高点与结构包络，特别壳体投影重叠处；比较规划φ/ψ、实际横梁角和编码器记录。
6. 逐项测试错误摆动侧、低抬升、邻座障碍、轴越界、超长轨迹、单轴STOP、USB断连、丢ACK及急停；必须在安全支撑状态恢复后重新标定。
7. 没有接触/载荷/电流/编码器反馈前，只能受监督逐阶段运行，不验收为自主行走系统。
