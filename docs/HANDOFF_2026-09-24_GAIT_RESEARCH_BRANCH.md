本分支已有n=24对照（报告第6.3节及粗扫CSV）：在相同理想几何、60段折线和0.1°验证网格下，整腿采样瓶颈为0.10291184R，连续下界0.09815885R；n=18分别为0.11794462R、0.10088278R。这与“爪端变远但整腿瓶颈下降”并不矛盾：两者指标不同。主线负责人应明确优化的是全腿安全瓶颈还是特定爪端距离，并同时报告另一项；不应直接用爪端改善替代全腿扫掠校验。

这里只补充版本与指标差异，未重新执行新主线或修改任何控制参数。合并本研究资料不应撤销主线的n=24修改，若有冲突应由主线负责人核对后处理。

## 1. 主线最重要的审阅内容

本分支交付的是分析后的控制逻辑与证据，不是已部署的新控制算法。如下区分已有机制、研究结论和后续实施工作，避免把研究候选直接当成生产参数。

| 项目 | 分析后的逻辑要求 | 本分支状态 |
| --- | --- | --- |
| 模态识别 | 按每一步当前支点、摆动端方位和公转方向重算LOW/HIGH，不永久绑定四个按钮 | 保留现有机制，补充数学解释和数据 |
| 两种角度路径 | LOW为反向比例自转；HIGH为同向集中调相；共用几何判据，不能只改DIR互换曲线 | 当前LOW和HIGH n=18均不变 |
| 坐标与关节角 | 世界自转Δψ与公转φ使用相反正方向；摆动关节Δq=Δψ+φ，支撑关节Δq=φ | 保留转换；文档明确符号与四动作 |
| 避让对象 | 对三条完整径向腿与全部相关高杆取最小距离，不只看爪尖或公转中点 | 采用现有模型复算并记录最近点对 |
| 优化目标 | 优先提高全程最小净间隙；单个姿态距离最大不能证明整段安全 | 给出max-min问题及候选证据 |

| 时间与同步 | 先确定安全角度路径，再安排共享时间进度；须覆盖关节全程极值、换向及机械能力 | 未修改SYNC、双轴DONE等待或限速逻辑 |
| 部署边界 | 扣除实体厚度与验证过的误差；平滑、量化或改变节点后须重新校验 | 尚无现场验收，不批准直接部署候选 |

建议主线维护者按以下链条理解和审阅，而不是只查看一个指数值：

```text

  → 本步LOW/HIGH分类
  → 世界自转—公转路径
  → 全腿扫掠高杆、连续间隙及全程关节约束校验
  → 共享时间进度、脉冲量化与误差预检

```

此链条概括现有机制与待完善验收条件，并不表示本研究已经实现了完整动力学或编码器闭环。

## 2. 研究结果如何影响控制决策

1. 当前HIGH的最紧位置约为公转进度28.18°、31.82°；30°中点较宽。只用中点余量决定是否运行会遗漏两肩扫掠风险。
2. 按0.01°研究网格，当前HIGH采样瓶颈约0.117656R；有限参数族候选n=19.6、中心30°约0.119795R，提升约1.82%。这是未扣实体厚度的中心线距离，不是现场净间隙提升1.82%的证明。
3. 候选调相更陡，最大自转／公转角度比由32.232升至34.444，摆动关节范围扩大，参考计划时间略增。未证明它在机械跟随、回差和负载方面更好。
4. 尚未求得全局最优，也未完成LOW的自由路径优化；目前不能据此直接替换主线曲线。
5. 源码中有关指数18峰速2.25倍公转的注释与角度导数不符，实际执行另有分段限速。此差异已记录到报告，本研究分支没有顺带修改生产源码或限速。

后续如批准控制算法实施，应另行明确可行路径集合、目标／硬约束、现场尺寸和误差预算，再验证新曲线的完整扫掠、关节范围、量化与时间安排。不要把本分支合并视为“候选已经部署”。
