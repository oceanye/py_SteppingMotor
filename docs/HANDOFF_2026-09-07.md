## 2. 现场使用流程

前置：协调页把 Mup1/Mr1/Mup2/Mr2 绑定到物理轴（Mr 必须旋转模式、
Mup 直线模式），轴参数已应用、已设原点。

1. **点动验证方向**：逐轴点动，确认"轴坐标增大"对应 ψ 增大（Mr）/
   抬起（Mup），在步态页方向符号栏选 +1/-1。
2. **记零**：把左三足摆到基准位（ψ=30°，即爪臂对准低节点方向），
   点 Mr1【记零】；右三足同理记 Mr2。记的是当前软件位置，不动电机。
3. **填几何**：量 d（六边形中心距）、爪臂长/节点环半径、壳体/爪臂/
   高节点等效半径、安全间隙 δ，替换占位值后【保存参数】。
4. **干跑**：选摆动侧（左 A→C 绕 B / 右 B→A 绕 C）→【干跑校验】。
   预览图绿点=低节点、红点=高节点、蓝虚线=三足中心轨迹、细线=爪臂
   采样、橙圈=最紧点。**报告必须"可行"才能开始**（开始时会再校验一次）。
5. **执行**：【开始 左 A→C】或【开始 右 B→A】建立执行器 → 反复点
   【✓ 确认并执行本阶段】：确认型阶段（S0/S1/S5/S7）只推进，
   运动阶段（S2 抬足 / S3 相位调整（通常自动跳过）/ S4 公转+自转
   （12 段）/ S6 落脚）弹确认框后执行。随时【⛔ 中止】。
6. 一次 A→C 完成后，另一侧做 B→A（镜像），即文档的轮换循环。

## 3. 数学模型与代码映射

- 平滑进度 `S(s)=10s³-15s⁴+6s⁵`：`smoothstep5`
- 公转 `φ(s)=60°·S`、自转 `ψ(s)=30°+120°·S`、横梁 `β=180°-60°·S`
- 关节角增量：摆动侧 Δq=+180°、支撑侧 Δq=+60°（`SWING_/SUPPORT_JOINT_DELTA_DEG`）；
  S4 按 `S(s_i)` 分段，段内摆动/支撑速度 3:1 保同时完成
- 轨迹采样与间隙 `D=dist-r_爪-r_高点-δ>0`：`plan_swing_trajectory`
- 相位换算 `ψ = 30° + sign·(轴坐标 - 零位)`；S3 修正角走最短路径
- 角色映射：Mup1/Mr1=左，Mup2/Mr2=右（`coordinated_control.LOGICAL_ROLE_ORDER`）

## 4. 干跑暴露的设计疑点（重要）

文档 §3 只验证了**公转中点**位形（φ=30°，高点在两爪臂之间）。
干跑把整个 φ∈[0°,60°] 连续采样后发现了文档没覆盖的事实：

1. **起步/收尾段各有一个高节点从壳体正上方越过**（左摆动 = A 的 90°
   高节点、C 的 210° 高节点；右摆动镜像 = B·210°、A·330°）。
   三足中心圆弧路径与起点/目标六边形的邻弧高节点恒定贴近
   （最近距离 ≈ ring²/(2d)），**加大 d 也躲不开**（d=150..400 全不可行，
   数值验证过）。这不是 bug：节点在壳体（半径 12mm）正下方由抬升的
   壳体飞越，水平间隙无意义——但它**只能靠现场垂向间隙确认**，2D 模型
   判不了。干跑报告会如实列出这些"飞越节点"，S2/S5 确认清单要求目视。
2. **臂扫掠最紧点在起步后不久**（d=220 占位时约 φ=5.7°，+3.4mm），
   不是文档分析的中点。占位几何下可行；实测几何填入后必须重新干跑。

## 5. 安全边界（也写在步态页顶部警示条）

- **几何/半径/间隙全是占位值**（d=220 等）：实测覆盖前**禁止真机执行
  运动阶段**，只允许干跑。
- 位置是主机脉冲累计，非编码器实测；任何轴 ABORT 后位置不可信，
  需重新校准并重新记零（运动链路自身也会拒绝运动）。
- 步态速度换算脉冲率超过 `PULSE_RATE_WARN_PPS` 时直接拒发该段。
- 每组等待超时 = 3×理论时长 + 15s，超时按失败停轴。
- 中止 = 四个绑定轴全部立即 STOP + 执行器状态置 aborted。
