# 2026-10-05 分发190 mm默认配置与数字孪生并排显示

## 范围

本轮在 `codex/twin-window-gitea-review-2026-10-04` 延续此前独立分支成果，
对应用户两项要求：190 mm写入配套分发配置，平面移动数字孪生与曲线左右并排。
本轮不修改 HIGH/LOW 避让曲线、四动作分类、SYNC指令、固件、标定规则或真实电机执行流程。

## 1. 默认尺寸随代码交付

新增 `motor_control.gait_planner.default_gait_params()`，桌面初始化及缺失/损坏配置回退统一调用：

| 项目 | 新桌面默认 |
|---|---|
| 投影边长/腿中心到顶点 | 190 mm |
| 两模态有效中心距 | `sqrt(3)*190 = 329.08965343808666 mm` |
| 控制策略 | `two_mode_v1`，HIGH/LOW由后台按当前站位判定 |
| 旋转零位/签名/硬件指纹 | 未设置 |
| 标定确认 | false |

新增可跟踪样例 `config/gait_params.example.json` 和配置说明。样例不是自动加载的第二配置源，
新安装无需手工复制；测试保证样例解析后与默认工厂相同。其他既有默认执行参数不变。
边长190 mm来自用户确认；腿投影半宽4 mm、杆半径5 mm、安全间隙2 mm仍需现场实测核对。

兼容与保护：

- 本机有效 `.gait_params.json` 中明确保存的尺寸、速度、方向、零位和签名优先，不静默重写。
- 启动仍按已有安全规则清除标定确认，不把软件零位当成已确认的实际落脚位置。
- 读取失败或内容无效时显示警告，回退到190 mm、未标定的两模态参数，不覆盖原文件。
- 部分两模态文档缺少投影尺寸时补190 mm；显式保存的40 mm等值保持原样。
- 无策略字段的历史文档，以及 `GaitParams()` / `GaitGeometry()` 的旧API默认，保持历史兼容语义。
  新GUI默认使用上述工厂，而不是改变所有旧调用者的尺度和控制策略。
- 本机 `.gait_params.json`、绑定、校准、调参和日志仍被Git忽略，不纳入上传。

**这取代了前一份190 mm交接中“仅本机配置、不修改分发默认”的限制。**
已有现场配置若仍明确保存40 mm，应在GUI修改并保存投影边长，不能靠重新拉代码自动改现场参数。

## 2. 并排工作区

步态页及“大图窗口”统一采用 `ui/gait_charts.py`：

- 左侧：固定5×5六边形地图、姿态、累计路径，保留缩放/平移/起步选格。
- 右侧：六爪端到邻域高杆表面距离曲线，横轴时间（秒），纵轴距离（mm）。
- 中间分隔条可拖动；左右图同步拉伸。分隔条只调整视图，不修改运动参数或路径记录。
- 主程序默认宽度至少目标1480像素（受屏幕宽度限制）；大图目标1500×820，可最大化。
- 步态左侧参数栏默认350像素，窗口加宽时优先把宽度分给右侧图表。
- 小屏仍能滚动参数与操作区域；大图工具栏窄屏/高DPI时自动换成两行，保留中止/关闭按钮。

对应关系：

- 六爪采用左足蓝系、右足橙系；地图爪端路径与对应曲线统一颜色。
- 曲线增加六爪图例、距离网格和当前时刻竖游标。单步回放的游标与地图使用同一动画帧。
- 单步预览显示S4计划时间；累计模拟显示累计模型时间；实机显示现有采样时间。
  计划/模拟秒不包含通讯等待，不能据此推断实际用时。
- 沿用同一数据源、报告、历史和定时器。大图只是共享数据视图，不新增采样器或电机控制实例。
- 蓝色单步预览不累计；紫色模拟累计虚拟位置；红色实机按脉冲估算。未接编码器，仍不是实测位置。
- 关闭大图不停止主程序或正在执行的电机；停止实机仍应使用中止按钮。

曲线口径保持不变：**爪端点到杆表面距离，不是整腿扫掠净间隙**。
粗黑线为六爪距离最小包络，0代表杆表面，δ虚线仅作参考；曲线为正不代表整腿避碰认证通过。
最终执行仍受原有完整避让校验与实机标定门槛约束。
