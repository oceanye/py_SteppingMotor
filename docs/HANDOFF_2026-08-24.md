## 2. 轨道 D（DRV8871）首次调通——病根：VM 误接 3.3V

现象：GUI 按住前进，状态栏正常显示 `FWD · PWM 60% · 租约续租中`，电机不转。

排查结论（三层链路全部审查，软件无 bug）：

- GUI→固件协议 `TRACK,D,FWD/REV,duty[,lease]` 两端格式完全匹配；
- 轨道代码与六轴步进同为 8-04 进入 GEAR 构建，板上固件必然包含 TRACK；
- LEDC 通道 4/5 与减速电机 0–3 无冲突；GPIO40/41 与 RS485/急停/步进无冲突；
- 全部历史日志（含 raw 串口记录）TRACK 出现 0 次——本次为首次实机测试。

真凶（用户现场确认）：DRV8871 模块的 **POWER ± 端子（即 VM）误接 3.3V**。
DRV8871 唯一电源输入是 VM（6.5–45V），无独立逻辑电源；3.3V 低于欠压锁定
阈值，输出级全程关闭，故固件回执正常而电机纹丝不动。IN1/IN2 本就兼容
3.3V 逻辑，接 GPIO40/41 无需改动。

修复：POWER ± 改接轨道电机额定电压的独立电源，共地保持。改后即转。

**给后人的坑位记录**：DRV8871"固件 OK 但电机不动"→ 先量 VM 是否 ≥6.5V；
模块丝印 VM 针脚与 POWER 端子常为同一网络。轨道操作不打 GUI 日志（只更新
状态栏），排查时注意 raw 串口日志才有 TX 记录。
