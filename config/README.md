# 随仓库分发的步态参数样例

`gait_params.example.json` 描述本机构的新桌面默认：两模态自动避让，正六边形俯视投影边长 **190 mm**。
两模态的中心距自动按 `sqrt(3)*190 ≈ 329.089653 mm` 派生，无需再输入。

新安装没有 `.gait_params.json` 时，GUI直接使用代码中的 `default_gait_params()`，
**不需要复制样例**。样例不是第二份运行时配置，也不会在启动时自动覆盖本机文件；
回归测试保证样例解析结果与代码默认一致。

如果本机已有 `.gait_params.json`，仍优先读取其中明确保存的尺寸、速度、方向、零位等。
需要把旧占位40 mm改为本机构190 mm时，在GUI“几何参考”修改投影边长并保存，
重新评估、确认标定；**不要整份覆盖现场配置**。无模式字段的旧文档仍按旧策略解读。

此样例没有端口、电机绑定、PPR/传动比、旋转零位、标定签名或标定确认。
未确认的腿投影半宽4 mm、杆半径5 mm、安全间隙2 mm沿用既有默认，仍需现场核对。
安装/加载190 mm默认不等于实机校准完成；程序不会因此自动发出运动命令。

详情见 [默认配置与并排显示交接](../docs/HANDOFF_2026-10-05_DEFAULTS_AND_SIDE_BY_SIDE.md)。
